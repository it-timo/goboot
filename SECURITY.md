# Security Policy

## Supported versions

Security fixes are provided for the latest released goboot version. Reporters
using an older version may be asked to verify the issue against the current release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's [private vulnerability reporting](https://github.com/it-timo/goboot/security/advisories/new)
channel. If it is unavailable, contact the repository owner privately through GitHub.

Include the affected version, reproduction steps, impact, and any known mitigation.
The maintainer will acknowledge a complete report as soon as practical and
coordinate disclosure after a fix or mitigation is available.
